# Nocturnal — every command

Generated by the Nocturnal engine from its command catalog; rewritten whenever an updated engine starts. `*` marks a required parameter. Send a command as MCP tool `<tool>`, `noc cmd <command> key=value`, or `POST http://127.0.0.1:17410/cmd { "type": "<command>", "payload": {…} }`. What to use them for: [`guide.md`](guide.md).
